# VV15 第二圈斑马线自动倒车入库

源码基线是用户提供的 vv(15).zip。原程序的斑马线识别判据、巡线算法、PWM2舵机、
3040000ns周期、偏移95、电机通道及初始化顺序继续使用。

## 流程

原赛道巡航 → 第2次有效斑马线确认 → 完成原有反转/停车动作 → 重新前进，
首笔非零PWM写入成功时启动阶段1计时 → 按VV原算法巡线 → 到时电机归零 →
停车设置倒车方向并等待settle_time_s → 阶段2第一倒弯 → 可选阶段3 →
阶段4第二倒弯 → 阶段5库内直退 → 阶段6停车记录 → 保持停车等待退出。

第2次有效识别沿用原VV的计数，不另造圈数识别。只接管一次，不会因重复看到斑马线
而重启计时。原参数中的“第二次识别延时永久停车”被新流程替代，旧自动车库流程不参与。
进入接管后不再响应环岛、锥桶、斑马线等赛道动作，仅保留阶段1的原巡线管线。

斑马线当前参数是右轮反转12000ns/800ms、停车窗口3200ms，两者重叠计算，
均不计入阶段1。阶段1不依赖反转结束回调，关闭斑马线反转仍可正常停车后起步。
计时起点是输出写入成功，不是编码器证明已经产生物理位移；编码器原生rps同时记录。
控制循环约20ms，停止时刻存在一轮控制周期及系统调度误差。

阶段1正常取图。开始倒车后，图像线程停止录像并释放相机；阶段2～6不取图、不录像。
电机计时在电机线程执行，不依赖图像线程。阶段1连续无有效图像达到line_lost_s会故障停车。
等待恢复起步时超过line_acquire_s仍无有效图像，也停车而不启动倒车。

## 编译、上传、启动

在Linux虚拟机中，把源码解压到共享文件夹，进入源码目录执行：

```sh
bash build.sh
```

脚本在`$HOME/builds/vv15_auto_parking`本地编译，避免HGFS并发编译问题。
编译后输出`vv_auto_parking`及`vv15_auto_parking_board.zip`。不会在x86虚拟机运行龙芯程序。
需要原VV的LoongArch交叉工具链和目标OpenCV，OpenCV路径由build.sh自动寻找。

上传`vv15_auto_parking_board.zip`到板子的`/home/root/gy2/vv15_auto_parking`，执行：

```sh
cd /home/root/gy2/vv15_auto_parking
unzip -o vv15_auto_parking_board.zip
sha256sum -c AUTO_PARKING_SHA256SUMS
chmod +x vv_auto_parking
sh ./run_auto_parking.sh --check-parking-config
sh ./run_auto_parking.sh
```

保留原VV的舵机开关操作：先关舵机启动，初始化完成、正常发车前Ctrl+C；再次启动，
按原车已验证的时机打开舵机。程序没有新加“首次准备”状态；启动调试窗口结束后会自动发车。
结束先关舵机再Ctrl+C。入库各阶段自动衔接，无需逐段Enter。
所有记录自动保存；此比赛自动入口不沿用调参工具的Y/N丢弃交互。

## 调参

入库只改`config/parking_tuning.vv.ini`，保存后重新启动。运行中不热改动作序列。
原巡线仍使用`image_params.txt`中的center_pratio、error_gain、steer_offset_deg及new_track_*参数。
零命令表示原VV的90+偏移95，不表示已测量的前轮机械直行。代码约定负左正右。

| 参数 | 含义与范围 |
|---|---|
| enabled | 1启用自动入库；0保持原VV巡航/终停行为 |
| trigger_zebra_count | 第几次有效斑马线事件接管，1..20，当前2 |
| reverse_right_only | 1倒车仅右轮，左PWM恒0；0双轮倒车 |
| line_lost_s | 阶段1有效图像最长间隔，0.05..0.5秒 |
| line_acquire_s | 斑马线停车结束后等待识线的上限，0.5..10秒 |
| motor_pwm_ns | 各阶段独立PWM，0或100..50000纳秒；方向由阶段决定 |
| motor_run_time_s | 首笔非零输出成功后的总运行秒数，0..120，支持小数 |
| steer_command | 固定转向命令，-90..90；阶段1固定0，运行时由巡线覆盖 |
| settle_time_s | 停车设置方向后的等待，0.5..5秒，不占电机运行时间 |
| hold_time_s | 主转向保持时间，0..120秒；0为整个本阶段保持 |
| correction_steer_command | 仅阶段2/4支持；第一弯修正为正，第二弯为负 |
| correction_hold_time_s | 修正持续秒数，0..120；0关闭修正 |

主转向到时 → 自动反向修正 → 回正；电机一直沿倒车方向运行，直到本阶段总时间到。
例如主转向1秒、修正1秒、电机3秒，则最后1秒回正直退。
主转向与修正不能超出总电机时间，否则启动前报错。阶段1/2必须启用，阶段3/4/5时间0可跳过。
阶段6电机必须为0，hold_time_s为停车后继续记录的时间。

包内角度、PWM、时间是调参起点，不是新车实测成功参数。先填入你已有的成功倒车参数，
再固定速度调阶段1持续时间以确定起倒点，然后按顺序调第一倒弯、第二倒弯、库内直退。

## 记录与验证范围

第2次斑马线接管时建立`captures/parking_auto/run_时间_进程号`，包含六个阶段CSV、
events.csv、入库参数和图像参数快照。CSV记录单调时钟、事件、阶段、电机运行时长、
转向命令、左右PWM、左右编码器rps和最后有效图像时间。不把rps冒充厘米/秒。
跳过的阶段也生成对应文件。Ctrl+C退出刷新记录；入库完成后保持电机为零。

新增测试覆盖触发去重、停车后恢复、成功写入后计时、相机无效时到时停车、丢线、
两步转向、跳过阶段、仅右轮与双轮模式、写入失败和六阶段记录。
本机软件验证不能代替实际龙芯板链接与实车路线验证。
