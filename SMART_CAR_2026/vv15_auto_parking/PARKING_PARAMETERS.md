# 入库调参完整说明（20261017.2）

调参文件：`config/parking_tuning.vv.ini`。以下列出该文件**全部受支持字段**，范围来自
`src/Parking/AutoParking.hpp`的读取与校验代码。小数允许用于转向、时间；PWM和计数只能整数。
修改、保存后重新启动；未知键、重复键、非法范围或组合启动前报错，不会静默代替你改值。

## 入口和共用参数

| 区段/参数 | 合法值 | 含义、当前值及调整方法 |
|---|---|---|
| session.start_mode | manual / race | 当前manual：按一次Enter直接进入巡线入库。race：原比赛巡航到目标斑马线停车后接管。旧文件缺失此项时按race兼容；想单独调务必显式写manual。 |
| session.enabled | 整数0或1 | 当前1。0回到原VV比赛巡航/终停，不是关闭电机；manual+0拒绝启动。 |
| session.trigger_zebra_count | 整数1..20 | 当前2，仅race使用；指原算法的有效事件次数，并非新加的圈数定位。manual忽略，仍保留合法值。 |
| session.reverse_right_only | 整数0或1 | 当前1：阶段2..5仅右轮倒退，左PWM始终0；阶段1双轮前进。0恢复双轮倒退。 |
| session.line_acquire_s | 0.5..10秒 | 当前3。从manual回车授权或race停车窗口结束起等待有效巡线图像的最长时间，超时停车。不是行驶时长。 |
| session.line_lost_s | 0.05..0.5秒 | 当前0.35。阶段1最后有效图像的容许年龄，超过则故障停车；无效图像不能续期。 |

## 每个阶段的参数

| 参数 | 合法值 | 含义与限制 |
|---|---|---|
| steer_command | -90..90 | 原VV软件转向命令：0软件回中、负左正右。阶段1必须0，实际运行用实时巡线误差；阶段2启用时必须负数；阶段4启用时必须正数；阶段6必须0。不是实测轮角或机械安全范围。 |
| settle_time_s | 0.5..5秒 | 阶段2..5：双轮先停、写方向成功后开始静止等待，然后启动电机。阶段1和6保留字段不使用；不占motor_run_time_s。 |
| hold_time_s | 0..120秒 | 阶段2..5从该阶段首笔非零电机写入成功开始保持主转向；0表示全程保持。正数到时转为修正（若开启），再回中。阶段1必须0；阶段6表示停车后记录多久再标记完成。 |
| motor_pwm_ns | 整数0，或100..50000ns | 各阶段独立PWM幅值；正负方向由阶段决定，不能填负数。周期50000ns，9000=18%占空比、12000=24%，不是18%或24%的实际速度。有运行时间的阶段1..5必须非零。阶段6必须0。 |
| motor_run_time_s | 0..120秒，支持5.5等小数 | 首次非零电机PWM写入成功后到自动停车的总时长。阶段1和2必须大于0；阶段3..5为0则跳过；阶段6必须0。时间起点不包含初始化、回车等待、识线等待、静止打轮等待或race斑马线动作。 |
| correction_steer_command | -90..90 | 仅stage_2/stage_4支持，其他阶段默认0且不能非零。阶段2开启修正时必须正数（右打），阶段4必须负数（左打）；关闭时建议填0。 |
| correction_hold_time_s | 0..120秒 | 仅stage_2/stage_4，0关闭修正；正数开启反向修正，要求主保持时间也大于0，且两次方向相反。修正后软件回中，电机可继续退到本阶段总时间结束。 |

“0..120秒”不等于每个字段都能随意为0：必须同时满足上表的阶段限制。
所有启用的阶段1..5必须满足：`hold_time_s + correction_hold_time_s <= motor_run_time_s`。
未写correction字段时默认为0（关闭）。六个stage区段及其五个基本字段必须齐全。
`line_follow_enable`、`mode=single`、`stage=2`、`motor_target_rps`、`servo_pwm`、
`speed_*_cm_per_count`等旧调参工具字段不属于本入口，不要粘贴进来。

本版阶段1固定使用原VV相机巡线，不能通过stage_1.steer_command给固定角度。
阶段2..6不取图、不录像，使用各阶段的时间/PWM/转向参数；本版不自动按超声波或虚线停车。
单轮倒车有左轮机械阻力和偏航影响，固定PWM不能保证固定距离，每次从同一位置开始对比。

## 六阶段目前示例与时间关系

| 阶段 | 电机幅值ns | 电机总时间s | 主方向/保持s | 反向修正/保持s |
|---|---:|---:|---|---|
| 1 前移巡线 | 9000，双轮前进 | 4 | 原VV实时巡线；hold=0 | 无 |
| 2 第一倒弯 | 12000，仅右轮倒退 | 3 | -40 / 1 | +5 / 1，最后1秒回中直退 |
| 3 分支直退 | 9000 | 0，跳过 | 0 / 0 | 无 |
| 4 第二倒弯 | 9000，仅右轮倒退 | 2 | +12 / 1 | -5 / 0.5，最后0.5秒回中直退 |
| 5 库内直退 | 9000，仅右轮倒退 | 1 | 0 / 0，全程回中 | 无 |
| 6 停止确认 | 0 | 0 | 回中，hold=2秒停车记录 | 无 |

这些是配置示例，**没有在当前实车验证成功轨迹**。用你已测好的值替换，不要理解为
按此参数必然入库。程序从阶段1自动连续执行后续非零阶段，没有中途逐段等待回车。
控制线程约20ms一轮，实际停车还受系统调度与惯性影响；计时写入成功不是物理位移确认。
完成后保持零PWM并等待Ctrl+C，结束前先关闭舵机开关。

## 怎么调：先固定速度，再找位置

1. 先保持`start_mode=manual`、`enabled=1`、`reverse_right_only=1`，每次把车放在同一斑马线前起点。
2. 先确定阶段1的`motor_pwm_ns`使直线巡线平稳。之后固定它，主要调`motor_run_time_s`找起倒点：
   停得早增加时间，停得晚减少时间，接近目标后每次改0.1～0.2秒。改变PWM后要重调时间。
3. 调阶段2：先固定PWM，调负向主命令及主保持时间，再调正向修正和其时间，观察接入方向。
   需要更大左打时增加负数的绝对值（例如-20到-25），不是把数值增加到-15。
4. 不需要分支直退就保持stage_3.motor_run_time_s=0。阶段4同样先右主转，再左修正。
5. 阶段5只调直退PWM及总时间，让终点距离合适。阶段6仅控制停止后的记录时间。
6. PWM建议每次改500～1000ns、命令每次改2～5、时间每次改0.1～0.2秒；一次只改一类，
   对照六阶段CSV检查。上述是调节步长建议，不是代码强制限幅，也不是机械安全认证。

## 原VV巡线参数（image_params.txt）

以下列出与本次巡线直接相关的原文件常用项；原文件还有赛道任务、环岛和录像等配置，
保持原值，其全部字段不能混入停车INI。范围来自RuntimeConfig读取代码。

| 参数 | 原代码范围 | 当前文件值 | 本次作用 |
|---|---|---:|---|
| center_pratio | 0.20..0.80 | 0.65 | 图像横向参考中心；改变会改变巡线基准，先用原值。 |
| error_gain | 0.5..8.0 | 4.0 | 原巡线误差到转向的增益，过大易摆动，过小转向弱。 |
| steer_offset_deg | -150..150 | 95 | 原VV安装偏移，保留原公式；本次不新增回中微调，先不改。 |
| motor_aim_speed | 0..30rps | 7 | 原比赛巡航闭环速度。**不控制入库阶段1..5的PWM**，入库调各阶段motor_pwm_ns。 |

原舵机计算：`setAngle(90 + steer_command)`，内部加原偏移，再算
`duty_ns = ((steer_command + steer_offset_deg)/90 * 5) * (3040000/100) + 1520000`。
因此软件命令0不等于1520000ns；偏移95时约为1680444ns。
改变原偏移会改变所有阶段的回中和转向，不能把旧servo_pwm=4470直接当成本车steer_command。
以上合法范围来自软件，不证明机构可承受极值；出现顶死时不要继续加大命令。

## 记录

每次manual授权或race斑马线接管创建独立目录`captures/parking_auto/run_*`，自动保存六个阶段CSV、
`events.csv`及实际停车/图像配置快照。跳过阶段仍有文件并标记SKIPPED。
字段含单调时间、阶段事件、电机运行时长、转向命令、左右PWM、左右原生编码器rps、
最后有效图像时间。rps不是厘米/秒；没有本车标定不能换算距离。
回车前结束不会生成停车CSV；原VV可选录像/实验记录仍由原image_params/启动参数控制。
记录无需Y/N确认；修改后重启，日志快照含本次实际start_mode。
