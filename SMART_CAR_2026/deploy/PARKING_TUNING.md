# 六阶段入库调参：舵机与单阶段电机

版本 **2026-10-09.1**。保留六阶段及可选的两次反向修正，阶段1新增前相机黑线巡线，保留单阶段电机定时执行、阶段持续时间记录。没有IMU，不开启比赛主程序，尚未接成完整自动入库。起点/终点由你测量；程序只记录阶段1持续时间，不把已有手推起点当成第二次斑马线起点。

## 只改一个文件

板上 `/home/root/gy/deploy/config/parking_tuning.ini`，源码模板 `deploy/config/parking_tuning.ini`。保留所有六段，只改选中阶段。初始选阶段1，阶段1～5左右电机各2000，运行时间均0禁用；阶段6三项全0。第一弯-10、第二弯+12、各5秒，额外修正默认关闭，沿用成功手推记录。

相关区段示例（不能代替完整文件，也不要重复添加区段）：

```ini
[session]
mode=single
stage=1

[stage_1]
steer_command=0
settle_time_s=0.5
hold_time_s=0
motor_left_command=2000
motor_right_command=2000
motor_run_time_s=0
```

新版模板阶段1含line_follow_enable=1；时间0只观察黑线和记录，不自动调整舵机。旧文件缺少开关默认关闭，不会自动开启。首次试电机，启动前把选中段 `motor_run_time_s` 改为短时间，例如1秒。时间0不初始化/输出电机，不改变方向GPIO；两个幅值都0也禁用。

| 参数 | 范围和含义 |
|---|---|
| `mode` | 有电机动作必须single；full只兼容全部电机禁用的手推流程 |
| `stage` | 1前移、2第一倒弯、3分支直退、4第二倒弯、5库内直退、6停止确认 |
| `motor_left_command` / `motor_right_command` | 原始PWM非负整数，0～各电机驱动报告的duty_max；左右独立调，无2000人为上限，不填写负数或小数 |
| `motor_run_time_s` | 0～120秒；0禁用，正时间配合非零幅值才执行；从实际输出成功开始计时 |
| `steer_command` | -15～15，受车辆上限限制；负左正右；这是命令，不是实测轮角 |
| `settle_time_s` | 设置舵机后静止等待0.5～5秒；电机模式保存重执行也等待 |
| `hold_time_s` | 动作允许后主转向保持0～120秒；0关闭舵机定时 |
| `correction_steer_command` | 第一弯右修正为正，第二弯左修正为负，也受舵机上限限制 |
| `correction_hold_time_s` | 0关闭修正；正数启用自动反向修正，范围0～120秒 |
| `speed_*_cm_per_count` | 0未标定，只报counts/s；有实测厘米/计数才输出cm/s |

**本版与队友程序统一为原始PWM：填2000就写入2000，不设2000或12000的人为上限。** 每路都以驱动报告的duty_max为硬件边界。例如duty_max=10000时，1000=10%、2000=20%、3000=30%、5000=50%、10000=100%；它们是PWM占空比，不是实际速度或PID目标速度。参数必须是整数；通信格式为uint16，不能超过65535，实车还要满足左右各自的duty_max。启动两轮前一起检查，任一路超界则报错，不截断、不先启动另一侧。

旧版用motor_command_range=50000缩放，满量程10000时填2000仅写400；本版在同一硬件上输出提高为原来的5倍。升级保留你的配置，但应先将选中阶段运行时间改为1秒再试方向，随后逐项调幅值和时间。旧文件3000、4000在硬件满量程10000时可直接作为原始PWM使用。本工具不使用calibration_vehicle.ini中的pwm_limit或hardware.ini中的motor_command_range限制电机调参；正式比赛控制仍保留原来的单位及限制。前进/倒退方向电平沿用硬件配置，不新增使能节点、不修改PWM频率。

终端与各阶段CSV的MOTOR事件输出units=raw_pwm、requested_left/right、left/right_written_raw、每轮gpio、duty_max、frequency_hz和write_result；written_raw是完成的软件写入载荷，-1表示失败后未知，不代表实测电机波形。写入异常仍尝试两路清零并退出；结束事件的written_raw为0，保留原请求值方便追踪。

阶段1自动前进，阶段2～5自动倒退，阶段6禁止电机动作。**电机总时间上限与舵机最后一步完成，先到者结束本段。**例如阶段2未启用修正、hold_time_s=5，电机设置10秒也会在舵机最后动作完成时停；要测较长直行，把直行段hold_time_s保持0。自动反向修正不重启电机总计时。

## 阶段1巡线逻辑与调参

借鉴用户提供的launch.pei.zip中center_black_track.cpp、image.cpp和control.cpp的思路，在当前工具独立实现。原项目的24/8直接输出PWM，本工具改用舵机命令及每秒变化率，不能照抄增益。没有移植IMU、环岛、斑马线计圈或分支交点选择，不替换当前仓库。

前相机截取纵向30%～95%，缩放160×82。每隔两行从近到远找黑线，要求宽度合格、左右都比黑线亮且逐行连续。只有真实找到的点参与置信度，短虚线间隔只连接相容的真实点。至少8行、近区至少3行、远区至少3行才可靠；目标发生大跳变拒绝该帧，不会以补线提高置信度。近区权重3、中区2、远区1，再加入少量远近趋势提前量。

控制误差＝多行加权目标−图像中心＋preview×（远区x−近区x）。误差与变化率按真实帧间隔滤波，用PD输出，设小死区、±8命令限幅、每秒30命令限速。黑线在右侧输出正命令，在左侧输出负命令，沿用你已确认的前进转向方向。没有把图像斜率称作IMU航向，也没有把命令当实测前轮角。

确认主线之前舵机保持0，电机不启动、不计前移时间。开始后每帧纠偏，**不重置电机总计时**；短暂不可靠帧保留上次角度，持续0.35秒则停车并回正，本次结果LINE_LOST。时间到同样停车、回正。独立电机线程在相机循环卡住时也执行停机和舵机回正；它不能中断阻塞的内核写入。没有在交点自动选主线的功能，先在明确的单条主线上验证本段。

巡线开启要求mode=single、stage_1的steer_command=0、hold_time_s=0、两轮幅值均大于0；motor_run_time_s=0仍可禁用电机并观察记录。其他五段仍使用固定角度/两步倒弯。

| stage_1巡线参数 | 默认 | 合法范围/意义 |
|---|---:|---|
| line_follow_enable | 1 | 0关闭、1开启；旧文件缺少时为0 |
| line_kp | 0.35 | 0～2，命令/像素；越大纠偏越强 |
| line_kd | 0.02 | 0～0.2，命令/(像素/秒)；受滤波约束 |
| line_preview | 0.25 | 0～1，远近线趋势提前量 |
| line_filter_s | 0.15 | 0.02～1秒，越大越平滑但延迟越大 |
| line_deadband_px | 1 | 0～5像素，小误差不追着噪声转 |
| line_max_command | 8 | 1～15且受车辆max_steer_deg限制 |
| line_slew_per_s | 30 | 1～100，每秒命令变化上限 |
| line_target_x | 79.5 | 40～120，160像素图上的中心基准 |
| line_crop_top/bottom | 0.30/0.95 | 顶0～0.75、底0.5～1、跨度至少0.2 |
| line_min_contrast | 16 | 整数8～80，两侧最低灰度差 |
| line_max_width_px | 26 | 整数4～40，黑线最大宽度 |
| line_lost_s | 0.35 | 0.05～0.5秒，持续丢线停车 |
| line_acquire_s | 3 | 0.5～10秒，启动前确认上限 |

旧阶段1录像的实际帧间隔约0.2秒，因此丢线容忍初值为0.35秒，避免一次漏检立即停车。旧录像识别统计：106帧中103帧可靠，另一段44个FRAME索引中可读取43帧且43帧可靠；后一段录像不完整，不能当作完整试验通过。前一段存在连续两帧不可靠，运行时会触发丢线保护。以上是初始调试值，尚未证明在实车上达到稳定巡线。先保持两路2000、motor_run_time_s=0，按Enter观察黑线有效性，Q结束。确认有效后退出，将时间改1秒试前进；逐次增加时间测第一弯起倒点。保持其他参数不变，偏差纠正太慢再小幅增加P；来回摆动先减P，必要时略增滤波。D、提前量、最大角度与速度分别调整，一次只改一项。持续偏向一侧要先查舵机机械回中，不直接靠改图像中心掩盖。

## 执行与切段

1. 启动前修改选中阶段参数，车放在你量测的起点，保持静止，运行脚本。等待授权时不采样、不写舵机、不启动电机。
2. **按一次Enter**开始记录并设置舵机，等待settle_time_s；无须第二次Enter。阶段1启用巡线时先等待至少3帧、跨度至少0.1秒的连续可靠黑线；确认上限3秒，失败则结束且不启动电机。新鲜前相机帧和有效编码器数据满足后执行电机，并从输出成功开始计算运行时间。禁用电机时提示手推/后拉。
3. 开启修正时：第一弯左打→右修正，第二弯右打→左修正，方向始终倒退；关闭时主动作到时回正。36.7°是线路夹角，不能直接填为舵机命令。
4. 时间到写两路电机0并回正，继续采集停机尾段。有效编码器约0.5秒连续零增量后结束；两秒内未确认则记录STOP_UNCONFIRMED并结束，不宣称停稳。零增量是观测条件，传感器故障仍可能影响判断。
5. 结束只显示一次保存提示，**直接按Y或N，无需回车**。Y保留本次全部记录，N丢弃目录；退出后你手动重启。
6. 切段：退出后修改stage再启动，分别试1→2→（需要时3）→4→5→6。实际不需要分支直退可直接选stage=4。第6段只静止记录，Q结束。

目前先分别标定电机阶段，不自动串行六段，不按虚线或超声波自动停车。旧手推full流程继续兼容。

## 控制键和保存更新

- P再Enter：停电机并暂停视频/传感器；电机试验同时取消舵机计时并回正，不能自动续跑。
- C再Enter：只恢复记录；之后再按Enter，重新设置舵机、静止等待并开始新试验。
- Q再Enter或Ctrl+C：提前结束、尝试电机零输出和舵机回正，再询问Y/N。人工退出不推断物理停稳。
- 正常运行中保存当前段参数即重新执行授权；先停当前电机，重新打角度并静止等待，再运行新参数。定时完成后结束，下一次手动启动。**P之后保存/C均不能绕过新的Enter授权。**改其他阶段、速度尺度、只改注释不重启当前段。
- 停机尾段确认期间拒绝新动作和配置更新，Q仍可提前退出，P/C仍可暂停/恢复记录。暂停后若两秒内未确认零增量尾段，以STOP_UNCONFIRMED结束；不会重新启动电机。
- 电机禁用的历史手推模式：P只暂停记录，舵机计时继续，C恢复记录；没有电机可停。缺少全部电机字段的旧文件按0处理；只补部分字段拒绝，三项需一起补。
- 非法/超限文件更新拒绝，合法旧参数和定时上限继续；稳定至少0.3秒才应用。旧试次计时事件不会结束新试次。

非零电机输出由主线程授权，独立线程只能写0。它在时间到或相机/编码器心跳超过frame_timeout_s（当前0.4秒）时停机，避免摄像头循环延迟无限续跑。它不能中断阻塞的内核驱动写入；软件零写入也不等于物理断电证明。实车电机极性、静摩擦、停止距离仍要短程确认。

每次运行建立独立 `captures/parking_tuning/rehearsal_.../`：

阶段1新增LINE_FEEDBACK（真实行数、近远目标、可靠性、滤波误差）与LINE_STEER_WRITE（实际命令及单调时钟时间）。目标及误差单位是裁剪后的160像素横坐标，不是厘米或实测航向。原始CSV包含帧时间、传感器读起止、编码器/超声波原始值、舵机写入/回正、按键和配置事件，以及电机启动/停止原因及左右带方向命令。各事件含阶段/试次/版本，未使用阶段只有表头；视频用CSV单调时钟定位，不依赖名义FPS。

速度表记录各阶段/步骤/试次的两轮窗口均速、运动窗口均速、峰值等；未标定只能比较counts/s，不是速度PID目标。

时间表记录允许动作时刻、电机输出成功时刻、零输出完成时刻、**stage_duration_s阶段执行时间**、首次/最后编码器运动观测时刻、运动观测跨度、连续零增量尾段和结束原因。阶段1执行时间会打印出来；授权等待、舵机静止等待、停机确认尾段和保存Y/N不计入电机阶段执行时间。运动观测跨度受采样频率影响，不是严格测量的物理运动持续时间。直接复用已有两轮样本，不额外读取或清空编码器。
