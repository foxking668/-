# 六阶段手推入库调参

本工具以运行中保存有效调参文件作为直接执行授权，也保留首次启动/手动切段的回车授权方式，由人手推/后拉；相机录像并读取编码器、前后超声波等已配置输入。没有电机、GPIO输出或IMU初始化，不执行图像建议，不自动确认入库成功。已有几何规划独立保留；此次是实车手动复现和找参数的入口，不要求补测量角。

当前版本2026-10-07.5。**第二阶段：2A左打倒弯 → 自动2B右打修正 → 零位**。右修正有独立角度、保持时间，也可以单独测试。保存有效参数直接执行的试次，在最后一步结束后停止采集、询问Y/N并退出；下一次手动启动，没有自动重启。

## 只改这一个文件

板上 `/home/root/gy/deploy/config/parking_tuning.ini`；源码模板 `deploy/config/parking_tuning.ini`。终端不接受角度数值。文件提供六组相同字段，修改角度或保持时间时只改对应阶段。

| 字段 | 作用 |
|---|---|
| `[session] mode=single` | 只调一个阶段；正保持时间到后回正并结束本次，重复测试需手动重启 |
| `[session] mode=full` | 普通回车路径逐段授权走六段；保存直接执行的试次到时结束整个程序 |
| `[session] stage=2` | 直接从第二阶段开始；改为1可从头走完整流程；运行中修改stage并保存会直接选择并执行该阶段；未改stage时保留实际当前阶段 |
| `[session] stage_2_step=first_bend` | 第二阶段从2A开始，启用右修正时自动接2B；改为`right_correction`只测2B，要求`mode=single`、`stage=2`；完整六段使用`first_bend` |
| `steer_command=-10` | 舵机命令；负数左打，正数右打。范围±15且受车辆配置上限限制；不是实测前轮角度 |
| `settle_time_s=0.5` | 第一次Enter设置舵机后，保持静止等待至少0.5秒；范围0.5～5秒，仅首次/手动切段路径使用，保存直接执行不等待 |
| `hold_time_s=5` | **运行中保存并成功写入新角度后**立即开始保持计时；首次/手动切段仍从第二次Enter开始。第二阶段启用右修正时，左打到时自动转入右修正；其余情况到时回正并按模式收尾。范围0～120秒，0关闭定时结束；命令为0且时间大于0也计时 |
| `[stage_2] correction_steer_command=5` | 2B右打命令，必须大于0且不超过15及车辆配置上限，独立于第四阶段 |
| `[stage_2] correction_hold_time_s=1` | 2B成功写入右打命令后保持1秒，再回到零位；范围0～120秒。0关闭右修正。完整左右两步要求左打命令为负、左打时间大于0 |

新模板默认只进入第二段：2A为-10/5秒，2B为+5/1秒；第四段+10/5秒，其余命令0/保持时间0。这些只是起始试值，不是最佳参数。36.7°是线路几何夹角，不能直接填成舵机命令。

**已有板上调参文件不会被安装覆盖。**旧文件仍可读取，但缺少右修正字段时不启用这个动作。请在已有`[session]`中加入`stage_2_step`，在已有`[stage_2]`中加入两个`correction_...`字段；不要重复创建同名区段，也不要删除其余阶段。相关部分如下：

```ini
[session]
mode=single
stage=2
stage_2_step=first_bend

[stage_2]
steer_command=-10
settle_time_s=0.5
hold_time_s=5
correction_steer_command=5
correction_hold_time_s=1
```

想单独调2B：启动前只把`stage_2_step`改为`right_correction`，手动把车摆到左弯已完成、准备右修正的位置。程序不自动补走2A。2B仍先用两次Enter授权，随后只执行右打、计时、零位、Y/N。测完整第二段再改回`first_bend`。

## 操作流程

1. 把小车摆到所选阶段的起始位置，保持静止，运行 `sh /home/root/gy/deploy/run_parking_rehearsal.sh`。启动就持续采集，每秒打印阶段名称和等待事项；等待授权时不计时、不自动退出，启动不写舵机。
2. **第一次Enter**：声明车身已停稳，授权设置本段角度。看到`WAIT_SERVO_SETTLE`保持静止；达到`settle_time_s`后显示`WAIT_PUSH_PERMISSION`。此时保持计时尚未开始。
3. **第二次Enter**：授权开始这一段手推/后拉，同时启动`hold_time_s`。按车轮自然滚动，不横向掰动车身。第六段是静态停止确认，保持车身静止。
4. 第二阶段启用修正时，2A时间到显示“正在自动切换2B右打修正”；不用再按Enter，**继续按原方向缓慢后拉**。看到2B已执行后保持右打指定时间，最后回到零位。其他阶段或关闭修正时只执行本段。single模式最后一步到时停止采集并询问Y/N；full普通回车路径继续记录。最后回正时你要自行停止推动。屏幕显示2A/2B、最近软件写入命令、当前步骤剩余时间及超声波原始值。
5. 在`full`普通回车路径中，实际停稳后按Enter结束当前段，录像和读数仍继续；下一次Enter才设置下一段舵机，之后等待并再次Enter才能推车。第二阶段左右两步正在执行时，Enter不会跳过右修正；提前结束用Q。左右两步都完成后才可用Enter切段。single最后一步正保持时间到后直接收尾；full第六段结束后停留在第六段，用Q退出。
6. **P再Enter**只暂停实验录像和传感器记录。左右计时、自动右打都继续；暂停不是停止动作。暂停期间保存参数仍会直接更新舵机。**C再Enter**只恢复记录，不重新执行角度、不重新计时。
7. 运行中直接编辑并保存文件，无需先暂停、无需R、无需C或再按回车：当前段有效参数或stage/mode/步骤选择变化，会执行并重新计时，取消旧计时；不等待settle_time_s或第二次Enter。第二阶段尚在2A时改右修正字段，会从2A重新执行整对动作；已经进入2B后只改右修正字段，仅重新执行2B，不返回2A；改左打字段则从2A重新执行（`right_correction`单独模式仍只测2B）。2B期间把修正时间改为0会结束并回正。**保存直接执行的试次，无论single/full，最后一步结束后均回正、停止采集、询问Y/N并退出。**只修改其他阶段参数不重启当前段；相同参数或只改注释不会重复执行。
8. 完成后实际停稳，**Q再Enter**提前结束、写入配置零位，再询问Y/N。Ctrl+C同样执行退出回零和保存确认。暂停期间计时规则不变，single或保存直接执行的试次到时也结束本次。程序没有电机停车能力；Enter/P/Q仅是人的停稳声明，不是传感器已经证明物理静止。
9. 结束采集、关闭文件后只显示一次“是否保存本次记录？按Y保存/N丢弃，无需回车”。**直接按Y或y**保留并显示SAVED；**直接按N或n**只删除本次独立会话目录并显示DISCARDED。有效按键立即处理；其他按键、空回车均忽略，不刷屏、不默认选择。等待回答期间不采集、不更新角度、不计时、不加载后续文件修改；回答后退出，下一次手动启动。

需要重复完全相同参数时，重新启动后使用两次Enter，无须修改文件制造变化。mode=full需要不中途退出时，启动前改好六段参数，再用普通回车路径逐段执行。

自动切换不增加第三次授权：开始2A时已授权按文件执行2A与2B。实现会在左打到时先写零位，再由主循环取得新鲜相机帧后写右打；切换可能存在短暂间隔，不承诺无间隙或精确的总用时。回零失败或相机帧失效会终止，不再继续右打。右修正结束后的零位表示软件命令回正，不证明车身已与分支平行；是否修正合适仍由你观察。

启动读取已有文件不会自行打轮；首次可以按上述两次Enter，也可运行中修改当前段参数并保存直接执行。文件每约0.2秒检查一次，内容稳定至少0.3秒且全量校验通过才应用；实际检测速度仍随摄像头循环耗时变化。编辑器临时清空文件、缺少字段、非法角度或文件读取失败时拒绝更新，保留原参数与原计时，下一次有效保存可恢复。

试验期间P/C/Q等控制键后要按Enter；结束后的Y/N保存确认直接按键，无需Enter。保存确认临时关闭终端整行输入和自动回显，完成或异常退出时恢复原模式；提示前的排队输入清除，不作为保存授权。不支持直接输入数字；一次收到多行回车会拒绝授权。等待期间输入的回车不会被留到下一状态自动执行。系统/设备阻塞仍可能延迟屏幕更新、按键处理和退出；独立舵机线程仅保证回正任务不依赖摄像头循环，不保证操作系统与硬件驱动的实时性。

## 六段各做什么

| 阶段 | 人工动作和结束判断 |
|---|---|
| 1 前移 | 名义回正，沿主线前推到准备起倒的位置；交点/起倒距离由你此次复现判断 |
| 2 第一倒弯 | 2A初试左打-10/5秒后拉，随后自动2B右打+5/1秒修正，最后零位；2B可单独调，不等同于第四段 |
| 3 分支直退 | 车身接近分支方向后，沿分支直退到准备接入库轴的位置 |
| 4 第二倒弯 | 初试右打+10后拉，使车身接入与主线平行的库轴；按实际结果分别调角度和保持时间 |
| 5 库内直退 | 回正后倒向终点，人工观察车体位置、前相机可见虚线和有效后挡板距离 |
| 6 停止确认 | 保持静止采集终点图像及测距，人工确认；可设正保持时间定时结束单段，或用Q结束 |

计时控制只能保证保持命令的时间。手推速度不同会改变这一段走过的距离和转过的角度，所以比较参数时尽量保持接近的推动速度，先只改一个参数。

## 每次启动的数据

采集期间记录暂存在本次目录。选择N删除本次六份CSV、录像与配置副本，保留原调参文件和所有旧会话；删除前验证绝对路径、目录名称及所有权标记，校验失败不删除。未回答Y/N不会自动保存或丢弃。

独立会话目录在 `/home/root/gy/deploy/captures/parking_tuning/rehearsal_.../`，不会覆盖上一次。固定创建这六份CSV：

```text
01_advance.csv
02_reverse_first.csv
03_reverse_branch.csv
04_reverse_second.csv
05_reverse_straight.csv
06_stop_confirmation.csv
```

未进入阶段只有表头，不伪造数据；第二阶段仍只有`02_reverse_first.csv`一份，新增`segment`列：`FIRST_LEFT_BEND`为2A，`RIGHT_CORRECTION`为2B，其他阶段为`PRIMARY`。自动2A→2B沿用同一个`trial`，重新保存执行则增加试次编号。编号在手动允许推动或保存文件直接授权执行时才增加，此前准备状态仍显示上一编号（首次为0）。数据包括按键、阶段状态、实际配置版本、配置命令与最近软件写入命令、相机读帧区间、逐通道原始数值/单位/有效性/系统调用返回值、舵机写入、保持计时开始和定时回正事件。自动右打的`HOLD_START`来源标记`AUTO_RIGHT_CORRECTION`。`AUTO_CENTER`只表示软件零位写入成功；`AUTO_CENTER_FAILED`是回正失败，不证明机械转角。

`config_1.ini`及后续版本保存当次实际应用的调参文件；传感器、车辆和硬件配置也保存副本。`camera_1.avi`等是共用录像，每1800帧换新片段，换片不停止记录；CSV的`clip/video_frame`用于定位画面，控制事件可引用最近已记录画面。视频标称FPS不代表真实时间：暂停间隔和实际帧时间必须看CSV单调时钟。编码器原始读数未换算里程/车身朝向，超声波原始值未自动换算厘米。

传感器在每次正常记录帧后读取一次，实际频率随相机/设备耗时变化；此工具不采用旧采集器的20ms后台采样。暂停期间不写实验样本、不读取传感器，相机仍取帧维持数据新鲜。暂停时发生的配置执行、舵机写入、保持开始和定时回正事件先保存在内存，C恢复或最终收尾时写回对应阶段CSV，保留实际发生时间；延迟补写的事件需按单调时钟排序，不能仅按CSV行号判断顺序。这不恢复暂停期间的录像或读数。结束后先关闭/fsync记录文件，再询问Y/N；Y才完成摘要并确认保存。

缺少允许省略的灰度通道会标记`UNCONFIGURED`，正常结束后的退出码为2；这是部分采集，不能算全部传感器有效。相机、存储或舵机失败报错、尝试回零，仍询问Y/N保留或丢弃可用记录；回正失败明确报错，不声称机械回正。终端断开/EOF无法回答时保留带.pending_session标记的暂存目录，报告SAVE_UNCONFIRMED，不认定保存；异常保留不完整文件标记KEPT_INCOMPLETE。帮助/配置校验与创建会话前的失败没有记录，无须保存确认。强制结束进程或断电无法弹出询问。
