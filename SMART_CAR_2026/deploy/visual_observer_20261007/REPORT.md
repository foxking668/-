# 近处线宽修正及手推视觉观察模式

2026-10-07。本轮完成停车阶段按图像行调整线宽限制，并在C++核心实现共用的VisualSteeringObserver。回放与manual_capture均调用该观察类；板上版本2026-10-07.1的源码已完成，尚未产生或运行新的LoongArch二进制。

## 最终实现

停车阶段的导引线最大宽度由上方的line_width_max_ratio向近处的parking_line_near_width_ratio渐变，近处默认0.15；其他阶段保留原宽度上限。局部对比邻域同步调整，继续要求两侧明暗对比、非蓝色边界和空间/时间连续性。不是将全图宽度阈值统一放宽，也没有声称完成相机透视标定。

观察模式默认不写任何执行器；与固定--steer-command互斥。它选取最初连续稳定的图像特征均值作为参考，并保留参考编号。横向及heading量都是归一化图像特征；参考不是已确定的主线语义身份、后轴居中位置或实际库轴。建议用于检查方向，不能直接当作入库转角。

默认要求至少0.65的线评分及近、中、远三段可见；连续确认帧数取配置confirm_frames，本车为3。帧时序必须严格递增，帧龄及新帧间隔均受frame_timeout_s约束，本车为0.4秒。前推/后推由参数明确选择，不通过噪声轮差反复切换。

诊断性建议使用图像横向差和远近差，前推/后推分别采用相反符号；不使用实际轮角、IMU或未标定编码器航向。命令幅度限制±5、变化率3命令单位/秒，未做闭环增益验证。丢线、歧义、突跳、时间异常、低质量或部分参考时撤销建议，输出空值而不是伪装成正常0误差；参考不被重新捕获的位置替换，恢复后重新连续确认。

manual_capture保留设备互斥锁和原唯一传感器采样线程。观察模式不构造ServoOutput或LinuxDeviceIo输出对象，不写退出回中命令。新增visual_observer.csv与图像一一对应，包含帧时序、参考编号、质量、错误图像特征、建议有效性及零执行器写入字段；原记录格式保留。

## 五项代码检查

1. 重复代码：观察逻辑只在visual_observer.cpp实现；录像回放与采集工具共用；板上采集与生产视觉共用processCameraFrame缩放和BGR转换；导引线候选共用宽度限制函数。没有复制设备采样、ServoOutput或整个视觉算法。
2. 命名：ManualMotion表示人工移动方向；lateral_error_image与heading_error_image强调图像特征；suggested_command与实际speed/steer输出分开；状态和reference_id明确质量及参考生命周期。
3. 结构：核心只读Observation和时钟，没有设备接口；命令行明确区分默认采集、固定舵机与观察；同一图像只观察一次，新增文件复用已有输出及关闭检查。数据检查脚本只校验真实C++结果，不实现第二套视觉或调舵算法。
4. 隐藏bug：阻止重复帧积分、非法时间、部分行的heading回退、非有限/越界特征、异常后建议残留和参考无声重置；确认计数饱和，避免长期溢出。记录Q退出前的该帧观察，确保CSV行数与录像一致。源数据路径内的输出在创建目录前拒绝；原数据哈希已检查。
5. 优化建议：前缀和保持局部对比计算效率；近处宽度按行处理而非全图放宽。下一阶段优先验证真实板上处理耗时和画面缓存，完善交点拓扑及局部预测恢复，再考虑实际执行建议；不能只以覆盖率变高决定启用闭环。
